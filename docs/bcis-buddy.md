# BCIS Buddy

BCIS Buddy is a renderer companion mounted only inside the authenticated Electron workspace. Its polished, layered SVG follows the supplied BCIS concept with a blue cap and headset, Wi-Fi chest emblem, cape, boots, and expressive face. Art, pose mapping, preference storage, controls, and motion styles live in separate modules under `apps/desktop/src/renderer/src/features/mascot/`. It has no network, database, filesystem, or preload access.

The current implementation provides subtle idle breathing, a short login wave, success feedback, processing motion, walking motion while dragged, thinking and warning/error expressions, connection-surprised expression, and a quiet rest pose after inactivity. It supports pointer-captured dragging from a dedicated handle, keyboard repositioning, minimize/restore, viewport clamping, system reduced-motion behavior, and optional short sound cues (off by default). It stores only position, minimized state, and sound preference in validated local storage. Version 2 migrates valid display settings from version 1; settings follow the Windows/Electron profile, not an authenticated staff account.

The renderer service layer emits fixed, non-sensitive event names after validated outcomes: subscriber creation, billing start/success/failure, posted payments, verified GCash posting, overdue account search results, report start/finish/failure, and verified backup creation. Connection status feedback is emitted by the connection screen when its readiness query observes a change. No subscriber names, balances, payment amounts, or proof content enter mascot messages. Payment success is emitted only when the validated API result has status `POSTED`.

This is a 2D CSS/SVG implementation, not a Rive/Spine rig or frame-by-frame sprite pack. The reference image guides an original local vector illustration; it is not imported as an animation source. Walking is limited to the user's drag gesture. These limits should be considered before describing Buddy as a full animation rig.
