# BCIS Buddy

BCIS Buddy is a renderer companion mounted only inside the authenticated Electron workspace. Its polished, layered SVG follows the supplied BCIS concept with a blue cap and headset, Wi-Fi chest emblem, cape, boots, and expressive face. Art, pose mapping, preference storage, controls, and motion styles live in separate modules under `apps/desktop/src/renderer/src/features/mascot/`. It has no network, database, filesystem, or preload access.

The implementation provides three personalities (Professional, Balanced, Playful), randomized short idle blinks/breaths/looks/stretches, sleep and wake reactions, and event-driven poses. Idle motion is timer-scheduled rather than continuous; it pauses for hidden windows, reduced motion, disabled animation, payment entry, and collection reconciliation. It supports pointer-captured dragging from a dedicated handle, keyboard repositioning, minimize/restore, viewport and reserved-lane clamping, theme-aware controls, and optional short sound cues (off by default). Versioned local storage persists position, enabled/minimized state, animation and sound preferences, size, and personality; v1/v2 settings migrate to v3 defaults. Preferences follow the Windows/Electron profile, not an authenticated staff account.

The renderer service layer emits fixed, non-sensitive event names after validated outcomes: subscriber creation, billing start/success/failure, posted payments, verified GCash posting, overdue account search results, report start/finish/failure, and verified backup creation. Connection status feedback is emitted by the connection screen when its readiness query observes a change. No subscriber names, balances, payment amounts, or proof content enter mascot messages. Payment success is emitted only when the validated API result has status `POSTED`.

This is a 2D CSS/SVG implementation with a transparent SVG background, not a Rive/Spine rig or frame-by-frame sprite pack. The supplied reference guides an original local vector illustration; the current character preserves its cap, headphones, Wi-Fi emblems, rounded face, gloves, boots, and blue palette but is substantially simpler and less shaded than the painted concept. Walking is limited to the user's drag gesture. These limits should be considered before describing Buddy as a full animation rig or a pixel-matched reproduction.
